            │             └───────────┬─────────────────┘
            │                         │
            │                         ▼

            │             │ LangGraph State Machine     │
            │             │ STRATEGIST → ALLOCATOR →    │
            │             │ ROUTE_OPTIMIZER → CRITIC →  │
            │             │ RESPONDER                   │
            │             └───────────┬─────────────────┘
            │                         │
            └────────────┬────────────┘

    ┌─────────────────────────────────────────┐

Segmented Mission System

┌──────────────────────────────────────────────────────────────────────────────┐
│                    CHECKPOINT-BASED REPLANNING                                │
└──────────────────────────────────────────────────────────────────────────────┘

    Mission animating...
            │
            ▼
    User clicks "Cut" at checkpoint
            │
            ▼
    ┌─────────────────────────────────────────┐
    │  freezeAtCheckpoint()                   │
    │  • Capture drone positions              │
    │  • Record fuel remaining                │
    │  • Mark visited targets                 │
    └─────────────────┬───────────────────────┘
                      │
                      ▼
    ┌─────────────────────────────────────────┐
    │  Build Segment from frozen routes       │
    │  Segment {                              │
    │    index: 0,                            │
    │    solution: {routes up to cut},        │
    │    cutDistance: distance_at_cut,        │
    │    cutPositions: {drone: [x,y]}         │
    │  }                                      │
    └─────────────────┬───────────────────────┘
                      │
                      ▼
    ┌─────────────────────────────────────────┐
    │  Replan remaining mission               │
    │  POST /api/solve_with_allocation        │
    │  • Filter out visited targets           │
    │  • Set synthetic_starts to cut positions│
    │  • Return new routes for remainder      │
    └─────────────────┬───────────────────────┘
                      │
                      ▼
    ┌─────────────────────────────────────────┐
    │  Build Segment from new solution        │
    │  Segment {                              │
    │    index: 1,                            │
    │    solution: {new routes},              │
    │    ...                                  │
    │  }                                      │
    └─────────────────┬───────────────────────┘
                      │
                      ▼
    ┌─────────────────────────────────────────┐
    │  committedSegments = [Segment0, Segment1]│
    │  Continue animation from Segment 1      │
    └─────────────────────────────────────────┘
